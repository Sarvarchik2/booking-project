  Node.js v22.19.0 использует новую версию OpenSSL
  react-scripts 4.0.3 использует старую версию webpack
  
  Конфликт! Нужен флаг: --openssl-legacy-provider

  start-frontend.sh автоматически добавляет этот флаг:
  
  export NODE_OPTIONS=--openssl-legacy-provider
  export SKIP_PREFLIGHT_CHECK=true
  cd frontend && npm start
