## 🐛 TROUBLESHOOTING

### Клиент не видит изменения статуса:
```
✅ Решение: Подождите 5 секунд (автообновление)
✅ Или обновите страницу вручную (F5)
```

### Кнопка "Give Feedback" не появляется:
```
✅ Проверьте: статус должен быть COMPLETED (зеленый)
✅ Проверьте: возможно отзыв уже оставлен
✅ Обновите страницу
```

### Отзыв не сохраняется:
```
✅ Проверьте: backend должен быть запущен (port 5001)
✅ Проверьте console в браузере (F12)
✅ Убедитесь что заполнены рейтинг И комментарий
```

### Backend ошибки:
