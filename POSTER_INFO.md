## ⚙️ 3. ФУНКЦИОНАЛЬНОСТЬ И ИНСТРУМЕНТЫ

### 🎯 Основные функции системы:

#### Для клиентов:
1. **Регистрация и авторизация** - создание учетной записи с безопасным хранением паролей
2. **Управление транспортными средствами** - добавление, редактирование и удаление информации о своих автомобилях
3. **Бронирование услуг** - выбор даты, времени и типа обслуживания
4. **Просмотр истории бронирований** - отслеживание статуса текущих и прошлых записей
5. **Управление счетами и платежами** - просмотр и оплата счетов
6. **Оставление отзывов** - оценка качества обслуживания (рейтинг 1-5 звезд)

#### Для механиков:
1. **Управление расписанием** - просмотр назначенных заказов
2. **Обновление статуса работ** - отметка выполнения услуг
3. **Личный кабинет** - управление профилем и специализацией

#### Административные функции:
1. **Управление типами услуг** - добавление и редактирование услуг с ценами
2. **Управление персоналом** - добавление механиков со специализациями
3. **Генерация счетов** - автоматическое создание счетов с расчетом налогов
4. **Аналитика и отчетность** - статистика по бронированиям и доходам

## 📊 4. DATABASE ERD (Entity-Relationship Diagram)

### Сущности (Entities) и их атрибуты:

#### 1️⃣ CUSTOMERS (Клиенты)
- 🔑 **customer_id** (PK) - уникальный ID
- first_name - имя
- last_name - фамилия
- email (UNIQUE) - эл. почта
- password_hash - хеш пароля
- phone - телефон
- address - адрес
- city - город
- state - область/штат
- zip_code - почтовый индекс
- created_at - дата создания
- updated_at - дата обновления

#### 2️⃣ VEHICLES (Транспортные средства)
- 🔑 **vehicle_id** (PK) - уникальный ID
- 🔗 customer_id (FK → customers)
- make - марка
- model - модель
- year - год выпуска
- vin (UNIQUE) - идентификационный номер
- license_plate - номерной знак
- color - цвет
- mileage - пробег
- created_at - дата создания
- updated_at - дата обновления

#### 3️⃣ SERVICE_TYPES (Типы услуг)
- 🔑 **service_type_id** (PK) - уникальный ID
- name - название услуги
- description - описание
- base_price - базовая цена
- estimated_duration - расчетная длительность (мин)
- is_active - активна ли услуга
- created_at - дата создания

**Примеры услуг:**
- Oil Change (замена масла) - $49.99
- Brake Inspection (проверка тормозов) - $79.99
- Engine Diagnostic (диагностика двигателя) - $99.99
- Transmission Service - $149.99
- Full Service (полное обслуживание) - $299.99

#### 4️⃣ MECHANICS (Механики)
- 🔑 **mechanic_id** (PK) - уникальный ID
- first_name - имя
- last_name - фамилия
- email (UNIQUE) - эл. почта
- password_hash - хеш пароля
- phone - телефон
- specialization - специализация
- hourly_rate - почасовая ставка
- is_available - доступность
- created_at - дата создания
- updated_at - дата обновления

#### 5️⃣ BOOKINGS (Бронирования)
- 🔑 **booking_id** (PK) - уникальный ID
- 🔗 customer_id (FK → customers)
- 🔗 vehicle_id (FK → vehicles)
- 🔗 service_type_id (FK → service_types)
- 🔗 mechanic_id (FK → mechanics)
- booking_date - дата бронирования
- booking_time - время бронирования
- status - статус (scheduled/in_progress/completed/cancelled)
- notes - примечания
- estimated_completion - расчетное время завершения
- actual_completion - фактическое время завершения
- created_at - дата создания
- updated_at - дата обновления

#### 6️⃣ INVOICES (Счета)
- 🔑 **invoice_id** (PK) - уникальный ID
- 🔗 booking_id (FK → bookings)
- 🔗 customer_id (FK → customers)
- invoice_number (UNIQUE) - номер счета
- invoice_date - дата счета
- subtotal - сумма без налога
- tax - налог
- total - итоговая сумма
- payment_status - статус оплаты (pending/paid/cancelled)
- payment_method - способ оплаты
- payment_date - дата оплаты
- notes - примечания
- created_at - дата создания
- updated_at - дата обновления

#### 7️⃣ INVOICE_ITEMS (Позиции счета)
- 🔑 **item_id** (PK) - уникальный ID
- 🔗 invoice_id (FK → invoices)
- description - описание
- quantity - количество
- unit_price - цена за единицу
- total_price - итоговая цена
- created_at - дата создания

#### 8️⃣ FEEDBACK (Отзывы)
- 🔑 **feedback_id** (PK) - уникальный ID
- 🔗 booking_id (FK → bookings)
- 🔗 customer_id (FK → customers)
- 🔗 mechanic_id (FK → mechanics)
- rating - оценка (1-5)
- comment - комментарий
- created_at - дата создания

### 🔗 СВЯЗИ (Relationships):

1. **CUSTOMERS ↔ VEHICLES** (1:N)
   - Один клиент может иметь много автомобилей
   - Каждый автомобиль принадлежит одному клиенту
   - ON DELETE CASCADE

2. **CUSTOMERS ↔ BOOKINGS** (1:N)
   - Один клиент может иметь много бронирований
   - Каждое бронирование принадлежит одному клиенту
   - ON DELETE CASCADE

3. **VEHICLES ↔ BOOKINGS** (1:N)
   - Один автомобиль может иметь много бронирований
   - Каждое бронирование для одного автомобиля
   - ON DELETE CASCADE

4. **SERVICE_TYPES ↔ BOOKINGS** (1:N)
   - Один тип услуги может быть в многих бронированиях
   - Каждое бронирование имеет один тип услуги

5. **MECHANICS ↔ BOOKINGS** (1:N)
   - Один механик может иметь много бронирований
   - Каждое бронирование назначено одному механику
   - ON DELETE SET NULL

6. **BOOKINGS ↔ INVOICES** (1:1)
   - Каждое бронирование имеет один счет
   - ON DELETE CASCADE

7. **CUSTOMERS ↔ INVOICES** (1:N)
   - Один клиент может иметь много счетов
   - ON DELETE CASCADE

8. **INVOICES ↔ INVOICE_ITEMS** (1:N)
   - Один счет может иметь много позиций
   - ON DELETE CASCADE

9. **BOOKINGS ↔ FEEDBACK** (1:N)
   - Одно бронирование может иметь отзывы
   - ON DELETE CASCADE

10. **CUSTOMERS ↔ FEEDBACK** (1:N)
    - Один клиент может оставить много отзывов
    - ON DELETE CASCADE

11. **MECHANICS ↔ FEEDBACK** (1:N)
    - Один механик может получить много отзывов
    - ON DELETE SET NULL
