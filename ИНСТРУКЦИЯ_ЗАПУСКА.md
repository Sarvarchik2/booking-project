# 🚀 Пошаговая инструкция запуска проекта Booking System

## Шаг 1: Убедитесь, что PostgreSQL запущен

```bash
# Проверить статус PostgreSQL
brew services list | grep postgresql

# Если не запущен, запустить:
brew services start postgresql@14
```

**Ожидаемый результат:** Видите `postgresql@14 started`

---

## Шаг 2: Откройте первый терминал для Backend

### 2.1 Перейдите в директорию проекта
```bash
cd /Users/sarik/Desktop/ds/booking-project
```

### 2.2 Запустите backend сервер
```bash
PORT=5001 DATABASE_URL="postgres://$(whoami)@localhost:5432/vehicle_service_db" node backend/server.js
```

**Ожидаемый результат:** 
```
Server is running on port 5001
Connected to PostgreSQL database
Startup migration: ensured mechanics.password_hash column exists
```

⚠️ **Важно:** Оставьте этот терминал открытым! Backend должен продолжать работать.

## Шаг 3: Откройте второй терминал для Frontend

## ⚡ Быстрый запуск (если все уже настроено)

Можно создать скрипты для быстрого запуска:

### Создайте файл `start-all.sh`:
```bash
#!/bin/bash
# Запуск PostgreSQL
brew services start postgresql@14

# Открыть backend в новом терминале
osascript -e 'tell app "Terminal" to do script "cd /Users/sarik/Desktop/ds/booking-project && PORT=5001 DATABASE_URL=\"postgres://$(whoami)@localhost:5432/vehicle_service_db\" node backend/server.js"'

# Подождать 2 секунды для запуска backend
sleep 2

# Открыть frontend в новом терминале
osascript -e 'tell app "Terminal" to do script "cd /Users/sarik/Desktop/ds/booking-project/frontend && export NVM_DIR=\"$HOME/.nvm\" && [ -s \"$NVM_DIR/nvm.sh\" ] && \\. \"$NVM_DIR/nvm.sh\" && nvm use 16 && npm start"'

echo "✅ Проект запускается..."
echo "Backend откроется на http://localhost:5001"
echo "Frontend откроется на http://localhost:3001"
```

Сделайте скрипт исполняемым:
```bash
chmod +x start-all.sh
```

Затем запускайте одной командой:
```bash
./start-all.sh
```

## ❗ Возможные проблемы

### Проблема: "Port 5001 already in use"
**Решение:** Убейте процесс, занимающий порт:
```bash
lsof -ti:5001 | xargs kill -9
```

### Проблема: "Cannot connect to database"
**Решение:** Убедитесь, что PostgreSQL запущен:
```bash
brew services restart postgresql@14
```

### Проблема: Frontend не компилируется
**Решение:** Проверьте версию Node.js:
```bash
node --version  # Должно быть v16.20.2
nvm use 16
```
