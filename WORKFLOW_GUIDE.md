## 🗄️ СТРУКТУРА ДАННЫХ

### Таблицы и связи:
```
CUSTOMERS (клиенты)
    ↓
VEHICLES (автомобили клиентов)
    ↓
BOOKINGS (бронирования)
    ├─→ связь с CUSTOMERS
    ├─→ связь с VEHICLES
    ├─→ связь с MECHANICS (назначенный механик)
    └─→ связь с SERVICE_TYPES (тип услуги)
         ↓
INVOICES (счета за выполненную работу)
    ↓
FEEDBACK (отзывы)
    ├─→ связь с BOOKINGS
    ├─→ связь с CUSTOMERS
    └─→ связь с MECHANICS
```

## 🔍 ОТЛАДКА

### Проверка данных в базе:
```bash
# Войдите в SQLite
cd /Users/student/Desktop/project/backend
sqlite3 vehicle_service.db

# Проверьте бронирования
SELECT b.booking_id, c.first_name as customer, m.first_name as mechanic, 
       s.service_name, b.booking_date, b.status 
FROM bookings b
JOIN customers c ON b.customer_id = c.customer_id
JOIN mechanics m ON b.mechanic_id = m.mechanic_id
JOIN service_types s ON b.service_type_id = s.service_type_id;

# Проверьте отзывы
SELECT f.feedback_id, c.first_name, m.first_name as mechanic, 
       f.rating, f.comments 
FROM feedback f
JOIN customers c ON f.customer_id = c.customer_id
JOIN mechanics m ON f.mechanic_id = m.mechanic_id;

# Выход
.exit
```

## ⚠️ ЧАСТЫЕ ПРОБЛЕМЫ

### 1. "No bookings assigned yet"
**Причина:** Нет бронирований в базе данных
**Решение:** Запустите `node backend/seed-test-data.js`

### 2. Статус не меняется
**Причина:** Backend не запущен
**Решение:** Проверьте `PORT=5001 node backend/server.js`

### 3. Ошибка 401 (Unauthorized)
**Причина:** Неверный пароль
**Решение:** Используйте `mechanic123` или `customer123`

### 4. "Average Rating: 0.0"
**Причина:** Нет отзывов в базе
**Решение:** Тестовые данные создают 1 отзыв автоматически

```

│   Статус    │            Описание                    │
├─────────────┼────────────────────────────────────────┤
```
